# السكب — واجهة الموقع فقط

هذه النسخة تحتوي على واجهة الموقع فقط، بدون خادم أو قاعدة بيانات أو مفاتيح API:

- `index.html` — هيكل الصفحة العربية.
- `styles.css` — التصميم المتجاوب والمظهر الفاتح/الداكن.
- `app.js` — التفاعلات، التسجيل، رفع الصوت، السلة، العداد، الباقات، ورسالة واتساب.

يمكن فتح `index.html` مباشرة في المتصفح، أو وضع الملفات الثلاثة داخل خادمك الحالي.

## نقاط الربط التي يضيفها الخادم

الواجهة الحالية تعرض تجربة تحويل محلية حتى تبقى قابلة للمعاينة. عند ربط الخادم، استبدل منطق `processVoice` و`finishProcessing` بطلب إلى API يقوم بـ:

1. استقبال الملف أو التسجيل.
2. تحويل الكلام إلى نص.
3. ترجمة النص للغة المختارة.
4. إنشاء ملف صوتي مترجم.
5. إعادة رابط صوت آمن إلى الواجهة.
6. السماح بالتحميل فقط بعد تحقق الخادم من حالة المجاني أو الدفع.

اترك كلمة المرور في الخادم أو نظام المصادقة، ولا تضعها داخل ملفات الواجهة.

## ملاحظة الحماية

المتصفح لا يستطيع منع تصوير الشاشة أو تسجيلها بشكل مضمون على كل أجهزة الجوال. الواجهة تحتوي على حجب للمحتوى عند مغادرة الصفحة أو فقدان التركيز، أما الحماية الأقوى فتحتاج تطبيقاً أصلياً أو سياسة حماية داخل الخادم.
